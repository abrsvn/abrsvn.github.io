Winter 2015: Meeting 1

Sun 25 January 2015 by Adrian Brasoveanu, Deniz Rudin, Nate Arnett, Karl DeVries

The first LaLoCo meeting this quarter will take place this coming Tue, Jan. 27, from 12:00 pm to about 1:15/1:30 pm in the Cave (same place as last quarter). We will continue where we left off last quarter, i.e., implementing parsers for English fragments in Python ACT-R.

We’ll work through some basic examples and Python ACT-R code Adrian, Deniz, Nate & Karl put together after our last fall 2014 meeting. Adrian will also present (possibly only in the 2nd/3rd meeting) some examples and Python ACT-R code our lab collaborator and friend from across the Atlantic Jakub Dotlačil put together to replicate some of the simulations reported in what is by now a locus classicus for this kind of investigations:

  • Vasishth, S., and Lewis, R. L.(2005). An activation-based model of sentence processing as skilled memory retrieval. Cognitive Science, 29:375-419
